## 🗺️ Обзор

Этот репозиторий - **полное, пошаговое и полностью проверенное руководство** по развертыванию собственного сервера Minecraft **бесплатно** на GitHub Codespaces.

Вы и ваши друзья сможете играть вместе на мощном сервере, доступном из любой точки мира, **не потратив ни копейки**, оставаясь в рамках бесплатных квот GitHub.

    Браузер → GitHub Codespace (Linux) → PaperMC → Playit.gg → Ваши друзья 🎮

**Что вы получаете:**
- 🖥️ **Виртуальную машину Linux** в облаке (2 ядра, 8 ГБ ОЗУ, 32 ГБ диска)
- 🟢 **PaperMC** - самый оптимизированный и стабильный сервер Minecraft на рынке
- 🧭 **Crafty Controller** - веб-панель для управления сервером в несколько кликов
- 🌐 **Playit.gg** - публичный туннель, чтобы друзья подключались без настройки сети
- 💾 **Автоматические резервные копии** и **скрипт предотвращения сна** в комплекте

## ⚠️ Ограничения и ответственное использование

### Бесплатная квота GitHub Codespaces

    120 ядро-часов / месяц  →  60 часов игры на машине с 2 ядрами

| Что делать | Чего избегать |
|---|---|
| ✅ Останавливать Codespace после каждой сессии | ❌ Оставлять работать круглосуточно |
| ✅ Проверять Settings › Billing & plans | ❌ Игнорировать потребление |
| ✅ Использовать для разовых сессий | ❌ Непрерывная эксплуатация как продакшен |

> ⚠️ Длительная работа игрового сервера **не соответствует** условиям использования GitHub Codespaces. Данное руководство рассчитано на эпизодическое и ответственное использование.

### Хранилище
- **32 ГБ** доступно на 2‑ядерной машине
- **Неверсионированные** данные теряются при удалении Codespace
- Используйте `backup.sh` и регулярно коммитьте резервные копии
